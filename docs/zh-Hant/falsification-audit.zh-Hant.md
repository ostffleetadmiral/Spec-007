# 證偽審計 — 負空間掃描

**狀態:**審計 1 — 壓力矩陣之後、SPEC-008 佈線之前;
**審計 2** — 行政覆權試驗場(`prototypes/`),一項封存在記錄中被打破
**範圍:**生態系中所有被廢棄或證偽的路徑,對照硬化基線重新檢驗
(37 探測壓力矩陣、Q128.128 陷阱邊界、雙錨紀律、SPEC-008 草案)。

**判定:**
- **SEALED** — 仍死;數學/工程證明成立。
- **BOUNDARY** — 在構想角色中已死,在已記錄的較窄角色中仍活。
- **RESURRECTED** — 新情境使其復活;設閘並重啟。
- **EXTERNAL** — 被程式碼之外的因素阻擋;誠實延後。

## 8. 掃描實際發現

- **審計 1:零死路復活** — 證偽成立。這本身就是發現:封存路徑由*算術與
  物理*封存(MTU、覆蓋半徑、認知成本),不受新機器讓步。
- **審計 2:一次復活** — 覆權掃描證明了該發現自身的保留條款:OVR-02 顯示
  N-02 的算術模型化的是*邊際*熵,而非正典結構網格的*聯合*熵。
  以算術封存的宣稱仍須指明是哪種算術。物理談判了一次 — 透過壓縮。
- **兩個潛在陷阱是作為缺陷的死路**(T-02、T-03)— 壓力彈幕已將其
  挖出並封存。
- **三個邊界重新分類**(N-04、N-05、N-06)— 在構想角色中已死,
  在較窄誠實角色中仍活。檔案的價值正在於此:知道哪個角色是真的。
- **情境轉移原則確認**:SPEC-008 改變了訊號移動的*成本*,
  從未改變相關的*法則*(N-03)。
- **審計 3:封存多數成立 — 兩項值得收窄** — 再 13 項挑戰:N-01
  有界文法通道與 N-04 正規化絆線為可行的較窄形式(依 §9 為晉升
  候選);T-01 包絡經實證移動(Golay d=5 *每個*傷口皆誤解碼 —
  安全半徑 ≤4);qmul4 於第三主機再度陣亡;khat 環繞/fp/降級封存
  經量測確認;物理本身成立(無訊號、傳送經典成本、CHSH |S|=2);
  M-34/36 維持 UNVERIFIED — 已計算,未符合。
