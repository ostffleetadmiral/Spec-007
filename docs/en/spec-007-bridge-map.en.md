# The Bridge Map — bidirectional evidence (debrief d10)

**Status:** L2 evidence layer · **Authority:** derived from the D-series
cluster debrief · **Pair:** `bridge-map-zh.html` · **Mechanism:**
`tools/bridge-map.mjs` → `bridge-ledger.json`, probe-enforced (BRG-01..09)
· **Coverage:** all 30 populated census roots + the archive corpus

The D-series sweeps carded every cluster root. This map goes further: it
records what the sibling projects **actually settle** — executable audits,
per-claim verdict tables, second implementations, and recorded experiment
data — and which dossier claims that evidence substantiates. Anchors are
mechanical checks over the sibling trees: a file that exists, a marker
that resolves, a verdict row that parses, a dataset that holds its schema,
a live audit suite that runs green. A sibling that moves degrades to
*absent*, never to *error* — deferral, not defect.

Evidence directions: **→** sibling evidence substantiating a dossier
claim; **←** fleet work the sibling carries; **⇄** a convention both
trees enforce.

classification boundary remain fleet-only disciplines.

settled rows, recorded data, executable audits — and nothing is promoted
past its evidence class. The framework-internal sentience instrumentation
remains a labeled operational definition, not a consciousness claim.*
