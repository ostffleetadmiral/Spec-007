# SPEC-007 協定規格書

**狀態:** 草案 1 — 一致性約束
**範圍:** 整數純核心與任何外部模組、執行時期或硬體節點之間的介面契約。
本文件即邊界;規定*何者可跨越*、*須付出何種代價*、*一致性如何證明*。

規範用語(MUST/SHOULD/MAY)採 RFC-2119 語義。

---

## 1. 分流不變式

本協定旨在嚴格分隔兩條通道:

| 通道 | 代價 | 內容 |
|---|---|---|
| **關聯** | 0 線上位元組 | 由成對種子導出之預共享態。本地計算,絕不傳輸。 |
| **信號** | ≥1 線上位元組,≥d/c 飛行時間 | 任何非共享種子態所先驗決定之位元。 |

一致性實作 MUST NOT 在無線上傳輸下交付信號位元。
凡觀測到 `bits_moved > 0 ∧ wire_bytes == 0` 即為斷裂(FRACTURE)——
實作缺陷,絕非特性。

## 2. 成對播種

1. 播種是唯一允許建立共享態之操作。
2. 節點 A、B 間之種子交換為每對一次性線上事件。N 節點全配對之線上
   成本為 O(N) 次投放,而所得關聯通道為 N(N−1)/2 — 糾纏紅利
   (`webDividendMilli`)。紅利係成對共享之*非強制推論*,非通道。
3. 種子材料 MUST 視為密鑰等級:種子導出串流具決定性,凡持種子者皆可
   重現該串流。
4. 未播種之配對 MUST 表現為無關聯雜訊(二進位槽位一致率約 50%)。
   未播種方之間出現關聯即為洩漏,MUST 通報為斷裂。

## 3. α-位元紀律

自關聯態提取價值須經線上古典酬載(α-位元)。順序具規範性:

```
measure_ns <= alpha_sent_ns <= extract_ns      (qetSequenceOk)
```

- α-位元*早於*發送方量測到達者 MUST 拒絕。
- 提取早於 α 到達者 MUST 拒絕。
- 因果逆轉非風格層級之協定違規;係物理違規,MUST 視為斷裂。

## 4. 線上計量

一致性節點 MUST 維護滿足下式之帳本:

```
∀ 已交付酬載:Σ 接收位元組 ≥ Σ 已記錄發送
```

- 幻影交付(收到未曾發送之位元組)即為斷裂。
- 封包重排、複製與損傷不構成計量漂移之藉口;不變式於位元組層級成立。
- 已建立之載波(持續點亮之穩定串流)編碼**零位元**
  (`dcCarrierBits = 0`)。資訊僅存於轉變,每次轉變皆支付
  `transitionFloorNs = d/c`。

## 5. 氫鐘槽位協調

槽位協調導自通用 21 公分譜線(1,420,405,751,768 µHz)。一致性節點
MUST:

- 由共享常數與本地量測之經過時間決定性導出槽位索引(`h1SlotBit`)。
- 容忍抖動至鬆弛邊界:抖動 ≤ 鬆弛時一致,MUST 於鬆弛 + 1 處斷裂
  (`h1JitterSafe`)。於 `elapsed=500`、`slot=1000`:鬆弛 = 500;
  抖動 500 成立,501 失效。
- 槽位一致所需握手回合數為零。

## 6. 決定性向量(互通契約)

`theue-golden-vectors` 輸出標準向量集:153 行操作 + 1 行摘要,涵蓋
Q128.128 底層(fromInt/fromRatio/add/sub/mul/div/pow/cmp/toInt)、
超越函數邊界(expFp,|x| ≥ 88 處截頂)、熔爐強化之角落(T=0、f=0、
u64 飽和)、糾纏謂詞、天文邊界與 i-vector 普查。

一致性要求**位元組級一致重現**:

```
digest|sha256|538237e6fb7060e899cdcada370ae13d34d3aacc5dee4f4c5f5e1307e26c920f
```

含逐行結果、錯誤標記(`!DivisionByZero`)與 `null` 視界。
已跨架構驗證:

| 目標 | 狀態 |
|---|---|
| x86_64-linux-gnu(ReleaseSafe) | 位元組一致(基準) |
| wasm32-wasi(Debug,Node WASI) | 位元組一致 |
| aarch64-linux-gnu(ReleaseSafe) | 可編譯;執行驗證待實體/qemu |
| riscv64-linux-gnu(ReleaseSafe) | 可編譯;執行驗證待實體/qemu |

**已知邊界:** Zig 0.13 下 wasm32-wasi 於所有 Release 模式失敗
(`LLVM ERROR: Unsupported library call operation!` — 最佳化暴露之
寬整數降階缺口)。Debug 建構位元組一致。記錄為工具鏈限制,非規格偏差。

## 7. 序列化與位元組序

- 所有整數序列化 MUST 使用明確位元組序:儲存資料與雜湊前像採
  `.little`,線上/網路序標頭採 `.big`(`science_address`
  u112/u128 標頭)。
- 雜湊前像 MUST NOT 嵌入原生配置整數(禁止對整數使用 `asBytes`)。
  *2026-10-06 修復:*`AuditChain.append` 序號與
  `shadowCommit`/`shadowCommitAt` nonce/coord 前像現改為明確
  little-endian 編碼 — 稽核鏈與位置綁定影子於大端/小端主機驗證一致。
- f32/bf16/f64 僅現於**格式邊界**(GGUF 解碼、JSON 解析、dtype
  標籤、存取子讀出、供給解碼器之測試夾具)。核心算術僅用整數;
  由下降審計之純度掃描強制執行(84 處邊界站點,0 違規)。

## 8. 一致性閘門

外部模組須依序通過下列閘門,方得介接晶格:

1. `zig build test` — 全模組測試。
2. `tools/descent_audit.py` — CLOSED(無環、無浮點算術違規、無孤兒)。
3. `tools/cross_target_check.sh` — 編譯矩陣 + 位元組一致摘要。
4. 熔爐(`science_fuzz` + `chaos-hammer.mjs`)— 全探針 HELD。
5. `emergence-watch.mjs` — 無禁用湧現;線上計量閉合。
6. `tools/continuity_audit.py` 與 `tools/twenty_re_audit.py` — 綠燈。
7. `tools/publish-check.sh` — 全閘門綠燈。

## 9. 拒絕行為(不可協商)

- 無線上成本之資訊 — 斷裂,絕非湧現。
- α-位元重排或逆因果提取。
- 幻影交付、虛構位元組或帳本漂移。
- 未播種方之間高於機率之關聯。
- 核心邏輯中之浮點算術。
- 定點路徑之靜默溢位/迴繞(截頂或報錯,絕不迴繞)。
