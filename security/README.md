# Hydra WAN Lab — `security/`

The communications over-test rig. Every Hydra node is **client + server
+ ledger**: it dials out over WebSocket, serves its own Rations relay,
and owns an independent chain keyed by `sha256(identity_pk)`. Global
routing identity is the node's `peer_id`; ledger identity is
`hash(publickey)`.

## Control-plane security (post-Kali sweep)

The lab publishes real ports — the control planes are token-gated:

- `hydra-node.mjs` — `HYDRA_TOKEN`; every endpoint except `/healthz`
  requires `x-hydra-token`. Per-run tokens are generated by
  `comms-suite.mjs` and passed to compose/local spawns via env.
- `wan-bridge.mjs` — `WAN_TOKEN`; all HTTP control (`/stats`, `/impair`,
  `/kill`, `/heal`) requires `x-wan-token`. The WS data plane is a wire,
  not a control surface — ungated by design.
- Relays run production posture in the lab: `RATIONS_ALLOWED_ORIGINS`
  is set; every WS client leg (hydra dials, wan-bridge upstream) presents
  `RATIONS_DIAL_ORIGIN=http://desk.local`. Headerless dialers are
  refused with close `4403`.
- `tools/serve.py` — hardened static server for the desk: no `Server`
  banner, no directory listing, GET/HEAD only, full security headers
  incl. CSP. Replaces `python -m http.server` for non-throwaway serving.

### Audit log — 2026-10-05 full sweep

The KALI pass caught a real deployment regression: the desk on :8080 and
:18777 was still being served by raw `python -m http.server` — version
banner disclosed (`SimpleHTTP/0.6 Python/3.13.15`), `/assets/` issued a
live directory listing, no security headers. `serve.py` existed but was
never deployed — an ops gap, not a code gap. Both ports now run
`serve.py`; KALI-06..08 flipped to HARDENED. Lesson recorded: a hardened
server that isn't running is not a control — the probe, not the file,
is the evidence.

## Compositions

**MIN — localhost single segment** (`--local`): one relay + two+ nodes on
one broadcast domain. Proves the smoke layer: identity announce,
presence→contact autofill, sealed send, mine+verify.

**MAX — docker multi-segment** (default): two isolated bridge networks
(`east`, `west` — no route between them), a segment relay each, two
impairment proxies (`wan-east`/`wan-west`) stacking **tc netem**
(NET_ADMIN, kernel-level) **and** the in-process proxy, plus
`node-bridge` — dual-homed on both segments, the bypass host.

```
 e1 e2 ── relay-east ◄── wan-east ╮
              east net           ├── node-bridge (dual-homed, own relay :8080)
 w1 w2 ── relay-west ◄── wan-west ╯
              west net
```

## Blockers exercised

- **Partition**: `/kill` on both WAN edges → zero cross-segment leaks
  (honest failure, not silent fallback).
- **Bypass**: with the WAN edge dead, leaves dial the dual-homed
  bridge's own relay directly — delivery resumes.
- **Impairment ramp**: 300 ms delay + 150 ms jitter + 8 % loss + 15 %
  reorder still delivers.
- **Churn**: node stop/start → re-dial → re-announce → presence
  relearns it.
- **Conn death**: relay heartbeat + packet loss kill sockets; nodes
  re-dial with backoff automatically.

## What it caught (real bugs, fixed upstream)

1. **`peer_discover` ping-pong DoS** (`family/Rations/src/p2p/node.zig`):
   a `count=0` discovery response is wire-identical to a request — two
   fresh nodes looped forever until the relay rate-limited both.
   Fix: empty response is never sent. Regression test in-file.
2. **No identity announce**: `connectPeer` registers a caller-declared
   sentinel; no `.connect` sender existed. `hydra-node` now broadcasts
   one on dial (+ every presence tick) — receivers register the real
   `peer_id`, which is what `routeToPeer` needs.
3. **Early `phone_send` transmits unsealed** before contact-key
   exchange — noted finding; presence-first ordering is the mitigation.

## Kali sweep evidence (penultimate red/blue/black/gray pass)

Run against the lab + desk from a Kali host:

- `nmap -sV` — surface mapped; python http.server version disclosed
  (fixed via `tools/serve.py`), JSON 404s on control ports (now 401).
- OWASP ZAP baseline — desk on http.server: version leak + missing
  security headers + clickjacking. Post-`serve.py`: all cleared; the
  only residuals are documented justifications (`script-src/
  style-src 'unsafe-inline'` — shipped pages carry inline boot code;
  `ws:`/`wss:`/`data:`/`blob:` sources — the desk dials remote relays
  and instantiates WASM).
- `msfconsole` auxiliaries — `http_version` returns blank against
  `serve.py`; `dir_scanner` finds only 403s; `options` empty.
- `tcpdump` inside `wan-west` (NET_ADMIN container) — marker payload
  delivered to inbox while 136 captured frames carried zero plaintext.
- Control-plane abuse, demonstrated live pre-fix: unauthenticated
  `/dial` and `/stats` executed remote actions. Now 401.
