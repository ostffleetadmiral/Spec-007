## 忠實性規則

1. 數值、方程式、章節順序、代號、笑話與任務語言在各忠實副本中原樣保留。
2. 忠實副本附有明確的不核准聲明，因源文含有危險及未經驗證的主張。
3. 技術更正、來源評級與駁回主張屬於 `spec-007-engineering-revision.en.md` 與 `spec-007-research-dossier.md`，不屬於忠實副本。
4. 繁體中文獨立副本統一使用 `不鏽鋼`、`氧化鈣`、`氫氧化鈣`、`介面`、`電網併網`、`身分`。
