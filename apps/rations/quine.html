Connect to Peer

        

          How connecting works: Rations is serverless — peers meet at a relay
          (a WebSocket endpoint that only routes encrypted frames; run one with
          node src/relay/server.js or use a peer's published port).
          Relay URL is the relay's WebSocket address.
          Remote pubkey is the peer's 64-character peer id — get it from their
          Dashboard or their phone contact card / QR. Once connected, publish
          presence in Phone & Messenger to exchange phone keys.

Virtual iPhone — vphone-control v1

        

          Port of the vphone-cli wire protocol: vsock:1337 length-prefixed
          JSON frames, command catalog, VM manifest authoring. The guest
          channel is virtio-vsock — unreachable from a browser — so a live
          session needs a host-side ws↔vsock gateway relaying identical
          frames.

          Author a manifest the host tool consumes:

Service Catalog
