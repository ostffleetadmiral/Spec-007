# SPEC-007 設計輸入審計

本審計記錄來自 OSTF 機密設計輸入的設計構想，在擴充入
`spec-007-expanded-engineering-spec.en.md` 時的分類結果。

## 來源連續性與出處

設計輸入為 OSTF 機密記錄（依 SPEC-004），不屬於公開儲存庫外觀。其中含有設計討論與少量化學方程式，但無外部 URL、DOI、標準識別碼、製造商數據表或可重現的模擬輸入。因此：

- 現已存在證據評級層：`spec-007-claim-verification.en.md` 將每項主要設計輸入主張評為 VERIFIED、VERIFIED-WITH-CORRECTION、EXTRAPOLATION、UNSUPPORTED 或 CONTRADICTED，並在可得處附第一手／機構來源。
- 已驗證背景：中國在光伏／風電的製造與部署主導地位（IEA／IEA PVPS／IEA Wind）、約 80% 的全球電石產能份額、約 3,000 kWh/t 的生產能耗、電石渣回收化學、負電價／限電市場數據，以及《發明保密法》歷史與統計。
- 已更正主張：電石能量密度約為 5–6 kWh/kg，而非「~12 kWh/kg」；中國累計光伏至 2025 年底約 1,464 GW（來源文件的 850 GW 為過時偏低，方向不錯）；風電至 2024 年底約 562 GW，而非 ~450 GW。
- 設計輸入的 ~65 W／1 kg／4 h 篩算估計隱含 ~6.6% 端到端轉換——接近已驗證的 ~5–6% 階梯篩算帶，但仍未經量測，不予晉升。輸入的三層 TEG 採收受放置位置 ΔT 限制：排氣邊界 TEG 可接近模組額定值，而反應器壁與冷凝段在 ~30–70 K ΔT 下運行，約回收 0.5–1.5%。輸入亦隱含發生器與燃燒器之間需有小型氣體緩衝（節流失配、冷卻殘氣）——記為待解設計目標。
- Novec 649 亞臨界 ORC 閘門（~169 °C 臨界）與 PDRC 板面積限制由 `spec007_expanded_calculations.zig` 強制執行。

- 政治、軍事與領導敘事依 SPEC-004（「7q」）列密，僅保留於機密設計輸入中，不得成為工程需求。
- 設計輸入文字視為設計假設或使用者需求，而非獨立證據。
- 化學與安全主張僅在獲研究檔案的外部來源或可執行計算台架支持時方予沿用。
- 設計輸入的數值主張保留為歷史輸入，但除非通過守恆、熱、機械、法規與經濟閘門，否則不晉升為需求。
- 權威連續性鏈為：原始 `spec-007.md` → 忠實譯本 → 研究檔案／經濟評估 → 擴充工程規格 → 計算台架。
- 現行外部證據列於 `spec-007-research-dossier.md`、`spec-007-economic-assessment.en.md` 及 `spec-007-expanded-engineering-spec.en.md` 的來源節。

## 更正後的高層結論

設計輸入含有有用的架構假設，尤其是化學、熱、轉換與使用者介面的分離。它們也含有反覆出現的樂觀錯誤：把名牌功率當淨功率、把輻射冷卻當無限冷源、把 Novec 的乾燥熱穩定性當 ORC 運行限值、把初步成本猜測當毛利。

擴充架構適合分階段研究計畫。它尚不足以證明可作為產品、載具或可獲利的卡匣生態系。
