## 2. 核心卡匣（「管體」）

**尺寸：** 直徑 50 mm × 長度 200 mm（約略值；以熱質量最佳化）

**材料：**

- **本體：** 316L 不鏽鋼，壁厚 2 mm
- **熱介面：** 鍍鎳銅冷板

- **滴液系統：** 壓電微泵，可變流量 0.1–0.5 mL/min

## 6. 安全協議（「監獄系統」）

**正常運作：** 滴液速率控制反應；乙炔由渦輪立即消耗。

**撞擊／碰撞：**

1. 擠壓感測器觸發（>5G）。
2. 破裂膜破裂。
3. CaO + H₂O → Ca(OH)₂（放熱但會固化）。
4. 反應物質在 3 秒內固化。
5. 乙炔生成停止。

**儲存：** 氣密封閉、氮氣覆蓋，保存期限 5 年以上。

**運輸：** 符合 UN 1402（電石）規範。

**彩蛋：** 監獄像長城一樣 — 以堅定站立來保護（城牆）。

## 7. 回收循環（歸還政府）

**泥漿成分：** 氫氧化鈣（Ca(OH)₂）＋未反應電石（CaC₂）＋碳雜質。

**回收流程：**

1. **回收：** 消費者將耗盡的刀片送回更換站。
2. **煅燒：** 加熱至 900 °C → CaO + CO₂（捕集 CO₂ 供工業使用）。
3. **碳熱還原：** CaO + 3C → CaC₂ + CO（電弧爐，以太陽能供電）。
4. **重新製造：** 將新電石裝入新的管體。

**循環碳：** 若使用生物炭進行還原，循環即為碳中和。

**彩蛋：** 此循環映照五行 — 土（Ca）透過火（太陽能電弧）回到金（電石），以木（生物炭）餵養並創造新的土（五行循環）。
