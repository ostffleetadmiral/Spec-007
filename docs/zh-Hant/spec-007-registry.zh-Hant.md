## 登錄規則

- 條目**隨里程碑**更新，不追溯重建。
- 文件 `狀態` 依 `draft → active → superseded → retired` 推移；退役須有引用替代文件之承繼列。
- AI 系統持有**零工程權限**（規則手冊第三條）：可登錄，不得核准。核准紀錄記載人類角色，不記代理人。
- `thoughts&convos/` 抽屜登錄表位於 `thoughts&convos/SPEC-004-REGISTRY.md`，依其自身僅可附加規則運作 — 屬機密，此處不予複製。
